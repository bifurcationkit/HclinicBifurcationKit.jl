## Homoclinic to hyperbolic saddle

The following tutorials present worked examples:

- [Autonomous electronic circuit (aBS from BT)](@ref): detection of a Bogdanov–Takens point and automatic branch switching to the curve of homoclinic orbits, using both orthogonal collocation and standard shooting.
- [Nonlinear laser model](@ref): computation of a branch of homoclinic orbits from a branch of periodic orbits, using orthogonal collocation or multiple shooting.
